## Dependencies

* python3 (>= 3.12.9-1)
* numpy (>= 1:1.26.4-3)
* scipy (>= 1.11.3-11)
* python3-zmq (>= 25.1.1-11)

### Installation on Ubuntu

```sudo apt install python3 python3-numpy python3-scipy python3-zmq```

### Installation on Fedora

```sudo dnf install python3 python3-numpy python3-scipy python3-zmq```

## Installing
